01Document

How to provide the document

02Language

Translation is done by a local model, clause by clause. It is slow and has not been reviewed for legal accuracy. The English version is always shown too.

03Simplify

  1. S_01

    Extract

    Text is read from your file. Scanned images need OCR first.

  2. S_02

    Split

    The document is cut into clauses using its numbering.

  3. S_03

    Context

    Each clause is paired with the parties, the definitions it uses and the sections it cites.

  4. S_04

    Simplify

    An AI model rewrites each clause. Clauses it is unsure about are flagged.

!Your data

The text of your document is sent to Groq's API to be simplified. Simplified clauses are cached on this server so repeat runs are faster. Results are kept in memory only until the server restarts. Don't upload documents you aren't allowed to share with a third-party service.
